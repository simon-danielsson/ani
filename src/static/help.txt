USAGE
    ani <opt|cmd>

META OPTIONS
    -h, --help            Displays this help message.
    -v, --version         Display program information.
    --guide               Display practical guide on typical usage.

OPTIONS
    -f, --file            Source file to read and/or modify, can be omitted if
                          a fallback has been added (see: --guide).

COMMANDS
    add, new              Add a new entry in an interactive prompt.
    ep, episode <id>      Change episode progress in an interactive prompt.
                          If episode number chosen is more or equal to the total
                          number of episodes of the entry, its status will
                          change to 'completed' by default.
    edit <id>             Edit an entry in an interactive prompt.
    info <id>             Print info of given entry.
    remove, rm <id>       Remove an entry (non-reversible).
    stats, summary        Display global statistics.
    rec, recommend        Let ani recommended you a plan-to-watch/on-hold entry.

    search <word>         Search entries by name, note, and tags.

    ls, list [cmd|flags]  List all entries
        watching          List watching
        completed         List completed
        on-hold           List on-hold
        dropped           List dropped
        planned           List plan-to-watch
        -r                Reverse sorting order asc./desc.
                          (modifier for sorting flags below)
        -n                Sort by name
        -s                Sort by user score/rating
        -u                Sort by last updated
        -y                Sort by entry release year
        -p                Sort by entry episode progress
